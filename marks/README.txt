Swarmada marks — v1.2, 14 Aug 2026

PRIMARY   swarmada-sweep-*     26 craft on an S-shaped path.
                               The mark. Use it wherever the surface allows.

ICON      swarmada-echelon-*   3 craft, wing high and leading (E3).
                               The sweep's reduction, for anything under 48px.

CROSSOVER 48px. At or above, sweep. Below, echelon. Also use the echelon on any
          surface that is large but narrow, where the sweep's diagonal has no room.

THESE THREE ARE ALWAYS THE ECHELON, whatever the guide calls primary --
the sweep has no readable structure at their size:
  * favicon / browser tab (16px)
  * GitHub org avatar (circular, ~40px)
  * CNCF landscape tile (~104x52) and the cncf/artwork square icon file

alternates/  swarmada-ess-*    Retired 14 Aug 2026. Letterform S made of 9 craft.
                               Drawn, documented, reproducible. Not in use.

COLOURWAYS  *-color  #0E8FA3 Signal Teal (clears WCAG 3:1 on white AND #0D1117)
            *-black  #101418     *-white  #FFFFFF (knockout)
            *-mono   currentColor - inherits CSS color

All: 96-unit viewBox, no strokes, no gradients, no raster, no font dependencies.
See Swarmada_Mark_Specification_v1_1.md for construction parameters and usage rules.

LIVE USAGE  swarmada-site: header + footer (echelon, Signal Teal, 21px/13px),
            favicon (echelon-color, linked directly from this directory).
            No other repo or surface carries these marks yet.
